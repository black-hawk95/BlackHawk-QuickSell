## QuickSell v4.0.0 for SPT 4.1.3

Includes the trader and flea sale fixes tested in the v3.4.0 test build.

- Trader quotes and confirmations account for weapon attachments. Tooltips recalculate after parts or stack counts change.
- Flea quotes and confirmations include attached items, including nested attachments.
- Fixed the flea confirmation crash caused by invalid patched IL.
- F12 **Allow flea market selling** blocks both QuickSell flea sales and offers made through the normal flea listing page when disabled. Flea buying stays available.
- Added F12 flea price refresh button and configurable refresh hotkey. Flea prices refresh on demand.
- Added F12 **Play sell sound for each item** option.
- Suppressed QuickSell price tooltips on trader-owned inventory items to prevent console overflow errors.

Extract the ZIP into the SPT root directory. When upgrading from the v3.4.0 test build, overwrite both plugin and server files. Requires SPT 4.1.3.
