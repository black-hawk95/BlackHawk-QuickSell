## QuickSell v4.3.0

- Flea tooltips now follow the configured listing percentage.
- Flea listing percentage range expanded to **25%–200%**.
- Ammo tooltips show the value of the full stack, not one round.
- Partially used meds, food/drinks, repair kits and resource items now scale flea listing value by remaining resource.
- Manual flea refresh keeps the old table active until the new table is ready, avoiding temporary incomplete tooltips.
- Flea pricing uses current generated market offers with SPT dynamic/base prices as fallback.
- Added separate F12 sound controls for trader sales and flea listings, with once-per-batch or per-item modes.
- Includes the precomputed tooltip/cache performance improvements and safe inventory reconciliation from the 4.2 development builds.
