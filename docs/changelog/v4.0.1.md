## QuickSell v4.0.1 for SPT 4.1.3

Packages the v4 sale and pricing fixes in **one client DLL**. The `BepInEx/plugins/QuickSell` folder now contains `QuickSell.dll` and `config.json`; `QuickSell.TestFixes.dll` is no longer required. The server mod retains its separate DLL in `SPT_Runtime/user/mods/QuickSell`.

**Upgrading from v4.0.0:** delete `BepInEx/plugins/QuickSell/QuickSell.TestFixes.dll`, then extract this ZIP into the SPT root folder and overwrite the existing files. Deleting the old helper is necessary because extracting a ZIP does not remove previously installed files.

Includes the trader attachment pricing fix, composite flea prices, normal flea selling toggle, manual flea price refresh and hotkey, and sell sound option from v4.0.0.
