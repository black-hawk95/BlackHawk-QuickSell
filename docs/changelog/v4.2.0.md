## QuickSell v4.2.0

- Reworked tooltip pricing around a precomputed cache so large backpacks and containers do not perform full tree pricing on hover.
- Added safe inventory-cache reconciliation after item moves, avoiding pricing while EFT is in a temporary remove/add state.
- Keeps nested container and attachment totals, trader/flea tooltips, and existing QuickSell selling behavior.
- No per-frame price calculation and no background worker touches EFT inventory objects.
- Added optional `[QSPERF]` debug logging in F12 for cache/precompute diagnostics.
- Flea tooltips now use the average of the currently generated market offers, with SPT/Live Flea Prices data as a fallback.
- Manual flea-price refresh now bypasses QuickSell's server cache.

- Added F12 sound controls: separate trader/flea toggles plus once-per-batch or per-item mode.

Target remains the SPT 4.1.x build used by this port.

- Smoothed the flea refresh transition so tooltips keep their current price until the refreshed cache is ready, then switch immediately without requiring an inventory reopen.
